# 포르투갈어(유럽) 버전 계획

영어패턴과 같은 앱·같은 방식으로 **한국인이 유럽 포르투갈어(pt-PT)를 배우는** 세션을 만든다. (2026-10-23 정함)

## 정한 것

| 항목 | 결정 |
|---|---|
| 배우는 사람 | 한국인. 설명·뜻·오답 설명은 지금처럼 한국어 |
| 포르투갈어 | **유럽 포르투갈어** 기준. 브라질식 표현은 쓰지 않는다 (예: 진행형은 `estou a fazer`, `estou fazendo` 아님) |
| 패턴 | **포르투갈어에 맞게 새로 짠다** (영어 230개 패턴을 옮기지 않는다). 포르투갈에서 바로 쓰는 말, 꼭 알아야 하는 문법 순서 |
| 누가 보나 | **운영자 코드만.** 다른 사용자는 지금처럼 영어 |
| 검토 | 사람 검토 없음. 점검 도구로 채점만 확인한다. 공부하다 이상한 문장이 보이면 그 세션만 고친다 |
| 음성 | mp3는 만들지 않는다. 브라우저 내장 음성(pt-PT)으로 읽는다. 기기에 유럽 포르투갈어 목소리가 없으면 브라질 목소리로 읽힐 수 있다 (아이폰은 Joana가 pt-PT) |
| 만드는 방식 | **세션 10개씩 완성해서 넣는다** (만들기 + 점검 + 앱에 넣기를 한 번에). 첫 묶음만 기반 작업을 같이 한다. 1~10이 들어가면 바로 공부를 시작하고, 공부하면서 10개씩 늘린다 |

## 운영자 코드에서만 보이게 하기

개인 코드는 공개 저장소에 적지 않는다 (코드가 곧 접속 열쇠).

- `&admin=1`로 들어가면 설정에 **"학습 언어: 영어 / 포르투갈어"**가 보인다.
- 포르투갈어를 고르면 그 코드의 서버 기록(Firestore `learners/<코드>`)에 `lang: "pt"`로 저장한다.
  → 같은 코드로 들어오는 **모든 기기에서** `&admin=1` 없이도 포르투갈어가 보인다.
- 다른 사용자는 설정을 볼 수 없으니 언어 값이 없고, 영어 그대로다.
- 진도·틀린 문제는 **언어별로 따로** 저장한다 (영어 기록과 섞이지 않게). 서버 문서에는 영어 기록을 지금 자리 그대로 두고, 포르투갈어 기록은 `pt` 아래에 둔다.
- Firestore 접근 규칙(이 저장소에 없음, 운영자가 따로 보관)은 원래 `done`·`progress`·`wrong`·`updatedAt`만 허용해서, `lang`·`pt`가 들어가면 **그 기록 저장 전체가 거부된다** (영어 진도 저장도 같이 실패). 2026-10-23 규칙에 두 항목을 추가한 파일을 만들었다:
  - `lang`: `"en"` 또는 `"pt"`만
  - `pt`: 맵, 안에는 `done`(목록, 500개 이하)·`progress`(맵 또는 null)·`wrong`(맵, 3,000개 이하)만. 다른 이름을 쓰면 거부되니 앱도 이 세 이름을 쓴다
  - **앱이 `lang`·`pt`를 보내기 전에** Firebase 콘솔 → Firestore Database → 규칙에 게시돼 있어야 한다
  - **2026-10-23 게시 완료** (콘솔에서 운영자가 게시)

### 채점 규칙 (포르투갈어) — `js/grade-pt.js`

- **악센트**(á à â ã é ê í ó ô õ ú ç): 빠뜨리면 "작은 실수"로 정답 처리하고 바른 글자를 보여 준다. 단, 악센트로 뜻이 달라지는 말(`é`/`e`, `está`/`esta`, `à`/`a`, `têm`/`tem`, `nós`/`nos` 등)은 오답. `há`를 `a`로 쓰면 오답
- **주어 생략**: `eu`·`nós`·`tu`는 빼도 늘 정답. 세션에 `subject: "eu"`가 있으면 패턴 동사 앞에 `Eu`를 넣어도 정답 (`Tenho fome.` = `Eu tenho fome.`, `Não quero` = `Eu não quero`)
- **축약**: `de + o = do`, `em + a = na`, `a + a = à`, `de + esta = desta`, `em + um = num` 등. 풀어 쓰면(`de o`) 오답으로 하고 이유를 보여 준다
- **대명사 위치(유럽식)**: `Chamo-me`, `sentar-me`처럼 동사 뒤에 붙인다. 하이픈만 빠뜨리면 작은 실수, 앞에 쓰면(`Me chamo`, 브라질식) 오답으로 하고 이유를 보여 준다
- **진행형**: `estou fazendo`(-ndo, 브라질식)는 오답으로 하고 `estou a fazer`를 알려 준다. 동사원형 자리의 -ndo(`costumo correndo`)도 알려 준다
- **예상 오답**: 악센트·하이픈만 다르게 써도 적어 둔 이유를 보여 준다 (단, 작은 실수로 맞는 정답이 있으면 그쪽이 먼저)
- **주어 넣기**: 문장에 이미 주어가 있으면(`Ela chama-se ~`) Eu를 넣는 모양은 만들지 않는다. 다른 사람 문장은 문제에 `subject: ""`
- **흔한 실수의 이유**: `sou`↔`estou`, `um`↔`uma`, `do`↔`da`, `no`↔`na`, ‘나’ 대신 ‘그/그녀’ 형태(`tem` → `tenho`), `não`의 위치
- 정답이 여럿이면(성별: `cansado`/`cansada`) 가장 가까운 것으로 작은 실수를 판정한다
- 대소문자·문장부호는 영어와 같이 무시
- 점검 도구는 `sou`→`estou`, `um`→`uma` 같은 바꿔치기가 정답으로 새지 않는지도 본다

### 콘텐츠 형식 (영어와 다른 점)

- 세션 파일은 `js/data-pt/pattern{N}.js`, 형식은 영어와 같다. 문장 필드 이름도 `en` 그대로 쓴다 (배우는 언어의 문장)
- `subject`: 넣어도 되는 주어 (위 "주어 생략")
- `wrong` 키는 악센트·하이픈을 그대로 둔 정규화 형태 (소문자, 문장부호 없음)
- 성별에 따라 바뀌는 말은 두 형태를 다 정답에 넣고 남성형을 대표 정답으로 둔다

## 묶음마다 하는 일 (10개씩)

1. 패턴 10개 정하기 (`pattern-list-pt.json`)
2. 세션 10개 만들기 (문법 설명, 예문, 빈칸·문장 문제, 다른 표현, 예상 오답과 설명, 팁)
3. 점검 도구 오류 0개 → 목록 다시 만들기 → 앱 버전 올리기
4. 커밋 (push는 운영자가)
5. 이 문서의 진행 표에 적기
